Добавляй сюда картинки из Pinterest с любыми именами, включая русские буквы и пробелы.
Форматы: JPG, JPEG, PNG, WebP, AVIF, GIF.
При запуске сайта через node server.cjs список собирается автоматически.
После добавления файлов просто обнови страницу.
Эти картинки чередуются с вашими совместными фото из assets/photos/.
Для Live Server, прямого открытия main.html или статического хостинга после добавления картинок выполни в папке проекта: node sync-photos.cjs
Эта команда обновляет списки обеих папок автоматически, без переименования картинок.
